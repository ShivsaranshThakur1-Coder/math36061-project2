# MATH36031 Project 2 — Fox–Rabbit Chase on a Circular Fence

This repository contains a complete, tested implementation and report for the MATH36031 Project 2 pursuit problem: a fox chasing a rabbit on a circular fence with a gap and an internal fence segment.

The project is structured as a small research-grade numerical experiment, with:

- Modular MATLAB code under `src/`
- Unit tests under `tests/`
- Automated test and profiling scripts
- Figure and animation export scripts
- A LaTeX report under `docs/report.tex`

## Problem summary

- Circular fence of radius 800 m.
- Rabbit starts at (0, 800) and runs along the fence to a burrow at angle $\pi/3$.
- Fox starts at (0, 0), uses a gap at (0, 300) and an interior fence segment between A (380, 600) and E (450, 320).
- Capture occurs if the fox comes within 0.1 m of the rabbit.

Two regimes are studied:

1. **Constant speeds**: fox and rabbit move at 16 m/s and 13 m/s.
2. **Diminishing speeds**:
   - $s_f(d_f) = 16 e^{-0.0002 d_f}$,
   - $s_r(d_r) = 13 e^{-0.0008 d_r}$.

## Repository structure

- `src/` — MATLAB implementation:
  - Configuration (`fox_rabbit_config`)
  - Geometry and line-of-sight (`segment_intersection`, `is_segment_blocking`, `is_line_of_sight_blocked`)
  - Target selection (`fox_target_point`)
  - Kinematics (`rabbit_position_const`, `rabbit_position_from_distance`, `fox_speed_var`, `rabbit_speed_var`)
  - Dynamics (`fox_rabbit_ode_const`, `fox_rabbit_events_const`, `fox_rabbit_ode_var`, `fox_rabbit_events_var`)
  - High-level simulators (`simulate_constant_case`, `simulate_variable_case`)
  - Tolerance and profiling tools (`simulate_constant_case_tol`, `convergence_study`, `profile_simulations`)
  - Plotting and animations (`plot_constant_case`, `plot_variable_case`, `export_all_figures`, `animate_constant_case`, `animate_variable_case`)

- `tests/` — unit tests using `matlab.unittest`:
  - `TestRabbitMotion`, `TestGeometry`, `TestFoxLogic`, `TestFoxVelocity`
  - `TestFoxOdeConstant`, `TestConstantScenario`
  - `TestVariableSpeeds`, `TestVariableScenario`

- `docs/`:
  - `report.tex` — LaTeX report (build with `pdflatex report.tex` in `docs/`)
  - `constant_case_paths.png`, `variable_case_paths.png` — path plots used in the report
  - (optional) MP4 animations if generated by export scripts

- Top-level scripts:
  - `run_tests.sh` — run all unit tests headlessly in MATLAB and assert success.
  - `run_profiling.sh` — profile constant and variable simulations (reporting steps and runtime).
  - `export_figures.sh` — regenerate all PNG figures (constant and variable case path plots).
  - `export_animations.sh` — generate MP4 animations for both regimes.

## Requirements

- MATLAB R2024b (or compatible), with:
  - `matlab.unittest` framework (included in recent MATLAB versions)
- TeX distribution (e.g. TeX Live) for building the report:
  - `pdflatex`
  - `siunitx`, `geometry`, `hyperref`

The project was developed and tested on macOS with MATLAB R2024b and TeX Live 2024.
